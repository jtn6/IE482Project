## Progress Report

Over the course of the last weeks, significant progress has been made in the development of the automated object sorting system. 
The foundational software and hardware components have been researched, assembled, and individually tested to prepare for full system integration.

On the software side, a Python-based computer vision program has been developed using OpenCV. 
The program uses a webcam to monitor a defined region of interest and detect objects based on color classification, namely red and blue.
Once detected, the software maps each color to a sorting command to detect it and either move the arm left or right. If no object is present, the system remains in a neutral WAIT state.

Communication between the computer and hardware has also been established. 
Serial communication was successfully configured between Python and an Arduino Uno through a USB connection. 
Sorting commands generated by the vision system can now be transmitted directly to the microcontroller.

On the hardware side, an SG90 servo motor has been connected to the Arduino and programmed to respond to incoming commands. 
The servo rotates to predefined left, right, and center positions, representing the planned sorting motions. 
A lightweight extension arm (a straw) has also been attached to the servo to simulate the physical deflection mechanism that will be used to remove objects from the conveyor belt.
The conveyor belt will serve as the transport mechanism during the final demonstrations. 
Preliminary layout planning has been completed for positioning the camera, conveyor, servo gate, and collection bins.

At this point, the major subsystems—vision detection, command generation, serial communication, and actuator response—have been completed. 
Full conveyor-based testing and timing calibration have not yet been performed.
The next phase of the project will focus on integrating all components into one complete system, and actually starting to test the sorting system.
